# 0006. Split canonical flow view from agent design view

- **Status:** Accepted (direction); specifics Proposed
- **Date:** 2026-09-29
- **Source:** Julian

## Decision

Two representation stages with a clear partition. First, a simplified layout that represents flow. Second, an agentic design stage that exposes a collection of design tools (e.g. sectioned boxes with headers, Venn-like groupings that place boxes in overlaps) so the agent can express hierarchy in a way that gives a human intuition for relationships. Different coding paradigms and applications will need different visual languages.

## Consequences

The specific primitive set, audit tests and dialects in docs/visual-grammar.md are Claude's proposal and not yet agreed. Also proposed: an animated flow ↔ design transition as the main audit tool.
