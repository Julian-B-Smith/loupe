# 0003. 2D prototype first, 3D later

- **Status:** Accepted
- **Date:** 2026-09-29
- **Source:** Julian

## Decision

The imagined end state is a 3D environment, but the tool must function as a 2D prototype first.

## Consequences

The data model must not assume 2D. 3D has to earn its place, for example by giving depth a meaning such as abstraction layer.
