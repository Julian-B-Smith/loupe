- **Queue item:** Q-010 (human gate: schema change). Decisions by poll 2026-10-16: the diff comes as its own PR in
  slice 2, before the crawler emits graph.json; targets are nodes with `builds` and `links` edges; the no-overlap
  check lives in the viewer's meter. `lens` is deferred while 0019 is Proposed.
- **Change:** `schema/graph.schema.json` accepts `loupe.graph/0.2` and `loupe.graph/0.3`; 0.3 adds `target` nodes
  with `targetType`, `builds` and `links` edges, `configs` on edges, `crawler.configurations` (required in 0.3) and
  `crawler.notEvaluated`, `build` in scope resolution, and `build` and `syntactic` in evidence resolution (required
  on crawl evidence in 0.3, via `if`/`then` on the declared version). `schema/view.schema.json` adds
  `settings.offsets`. `tools/loupe-check.mjs` adds G7 (configuration names unique, `configs` declared), G8 (build edge
  shapes), V8 (offset keys) and S0 (a schema that does not compile is an error, no longer reported as "install ajv").
  The viewer's layout lists overlapping top-level sections and `conserve()` counts each as unaccounted.
- **Found on the way:** the mutation harness called `check()` without a schema directory, so no S1 case could ever
  fail: schema validation never ran in the mutation tests. Fixed; four new S1 cases then caught. A broken schema was
  also swallowed by the same `catch` as a missing ajv.
- **Evidence:** 34 mutation cases (14 new) all caught; the 0.2 examples still validate. Overlap tests on both
  snapshots: none in the default layout, a section dragged onto its neighbour is reported and breaks the meter, a
