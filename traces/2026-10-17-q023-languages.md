## Second version

- **Code masks.** A Python mask (comments and docstrings blanked, strings marked). A small JS lexer: regex literals and
  template literals handled, code inside `${}` lexed as code. HTML comments blanked, inline scripts lexed as JS. Shell
  comments and heredoc bodies skipped. An import keyword counts only in code, with a real token boundary, and a
  specifier must look like a module name.
- **Writes.** `generates` is tied to the literal that is written: `open(<lit>, 'w')`, `<lit>.write_text`,
  `writeFileSync(<lit>, …)`, the word after `>`.
- **Bare names.** A literal with no `/` resolves only next to its file, never from the repo root.
- **Shell.** Shell paths are `search` (the shell resolves from its working directory).
- **Ordering and fallbacks.** The standard library is checked before same-named repo files; Node built-ins are listed.
  Computed imports go to `notEvaluated` (24 on HORDE). A link to a tracked binary gets the binary note.
- **Tests.** Every false edge the critic showed is now a negative test, plus read/write separation, shadowing,
  computed imports, bare names and the JS lexer cases. A plant (JS mask off) fails five tests.
