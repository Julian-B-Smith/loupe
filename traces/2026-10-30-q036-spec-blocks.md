# q036-spec-blocks — loupe-spec blocks for the diff tally and the matrix; the renderer reads them

- **Queue item:** Q-036 (from REFLECTIONS 2026-10-29; the matrix joined it by poll the same day). Human gate: schema.
- **Julian (poll, 2026-10-30):** the schema change approved in this shape: `diff-tally` joins `primitive`; the matrix is a
  view, not a primitive, named by a new `lens: "matrix"` in place of `primitive`; a `sizes` map (a name → a number ≥ 0)
  for values that are not tokens. The values reach the code through a generated module, and the oracle fails when it is
  stale. After the critic: "not hard-coded" means styling (every stroke, radius, dash, opacity, font size and colour);
  placement offsets stay in code as layout logic.
- **Change:**
  - `schema/loupe-spec.schema.json` (0.2): `oneOf` primitive or lens, `diff-tally`, `lens`, `sizes`.
  - `design/system/components/{diff-tally,matrix}/README.md`: their blocks; the prose names the block's sizes instead of
    repeating numbers, and says placement stays in `render.js`. `design/system/README.md`: the counts, the lens, the module.
  - `tools/specs.mjs` (new, `npm run specs`): every block → `design/prototype/specs.js` (generated, components in name
    order, keys as written, `notes` left out).
  - `matrix.js`: `MX` is the block's `sizes` object itself (renamed `MARKS` → `marks`). `render.js`: §4b the tally and
    `renderMatrix` read sizes, parts and states from `SPECS`; the matrix's `mark` part is now read (it was dead), the
    shaded cell has its own `shade` part (it borrowed the count's colour).
  - Token `dash-outside` ("3 3", tokens.json and tokens.css): the matrix's outside chip outline.
- **Byte comparison:** 111 tally and matrix frames over the ten stress cases (Design and fit, collapsed and zoomed, the
  diff, single and paired matrices at three zooms) are identical to main's renderer, apart from three spellings of the
  same value: `0.6` for `.6`, `var(--loupe-stroke-edge)` (1.25px) for the chip's `1.25px`, `var(--loupe-dash-outside)`
  for `3 3`.
- **Checks:**
  - `render.test.mjs`: every block validates; every token a block names is declared in tokens.css (critic M3); the schema
    refuses a block with both primitive and lens, with neither, or a non-number size; `specs.js` equals the generator's
    output (criterion 4: `./verify fast` runs this test).
  - `stress.test.mjs`, the Q-036 block: the tally and the matrix draw at the block's sizes, and follow a value changed in
    the module. Every one of the tally's 26 values and the matrix's 64 changes the drawing when changed in turn (critic
    M2), over frames that reach every state the blocks style: a built variant has a six-edge cell, a two-edge cell, both
    margins and an outside file. Only the compact tally form, a last resort no frame reaches, is exempt and named. The
    chips sit `chipGap` apart, a geometry check, because the gap is also read for the tally's width.
- **Plants (24, each caught in the end):**
  - **Round 1 (12):** chip height, chip radius, waffle square and a kind's colour hard-coded; `MX` a copy, and `MX`
    hard-coded; the matrix cell's and chip's fill hard-coded; a block edited without regenerating; `diff-tally` and
    `lens` dropped from the schema; the generator dropping `sizes`. The cell fill was missed at first, because no
    counted cell was checked; a frame at k 0.4 fixed it.
  - **Round 2 (10, after the critic):** the count font cap, the margin radius, the cell ring width and the chip gap
    hard-coded; the mark part ignored; the shade fill hard-coded; a block entry nothing reads; a token typo; `oneOf`
    dropped; sizes allowing strings. Two were missed at first: the count cap and the chip gap are each read in two places,
    so the sweep still saw a change. The count size is now computed once, and the chip gap has its geometry check.
